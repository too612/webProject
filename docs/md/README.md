# 문서 인덱스

이 폴더는 프로젝트의 최소 문서 체계를 유지하기 위한 기준 문서만 보관합니다.

## 우선순위

1. [.github/copilot-instructions.md](../../.github/copilot-instructions.md)
2. [core/system-architecture.md](core/system-architecture.md)
3. [official/official-domain-guide.md](official/official-domain-guide.md)

## 읽는 원칙

- 문서는 중복을 줄이고, 필요한 규칙만 유지합니다.
- 하네스 문서는 일반 작업 문서에서 제외합니다.
- 현재는 `official` 구조를 기준으로 정립하고, 이후 다른 대분류는 이 패턴을 확장합니다.
- 작업이 끝난 문서는 삭제하거나 정리합니다.
